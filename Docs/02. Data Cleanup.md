## 1.  Selecting Data for Joint Angle Estimation

The Wearable Biomechanics Data Cleaner serves as the preprocessing pipeline to extract, filter, and rename specific IMU sensor data for downstream kinematic analysis. It integrates directly with the `OpenDatasetStore` utility to transition data from raw formats into structured, processed entries.
### 1.1.  Core Processing Functions

The pipeline relies on two primary Python functions that utilize dynamic regular expressions to isolate correct data streams

- **`get_columns(df, devices, imus, axes)`**: Identifies valid dataset columns by matching specified device IDs, IMU numbers, and spatial axes. It executes the regex pattern `^.*?(?<!\d){dev}_IMU{imu}_{axis}$` to ensure exact device number matching and prevent partial digit overlaps.

- **`extract_and_rename_imus(df, imu_mapping)`**: Isolates the six primary telemetry axes (AX, AY, AZ, GX, GY, GZ) for designated sensors. It retains the underlying `Timestamp` data and reformats the column headers from their raw hardware IDs to target anatomical labels (e.g., yielding `RKP_AX`).

### 1.2.  Standardized Sensor Mapping

Data extraction relies on a strict configuration dictionary that maps final target node names to specific hardware devices and their internal IMU indices.

| **Target Node** | **Device ID** | Explaination                                      |
| --------------- | ------------- | ------------------------------------------------- |
| **RKP**         | 1             | Right Knee Proximal (Right leg, above the knee)   |
| **REP**         | 2             | Right Elbow Proximal (Right arm, above the elbow) |
| **LKP**         | 3             | Left Knee Proximal (Left leg, above the knee)     |
| **LEP**         | 4             | Left Elbow Proximal (Left arm, above the elbow)   |
| **RED**         | 6             | Right Elbow Distal (Right arm, below the elbow)   |
| **LED**         | 7             | Left Elbow Distal (Left arm, below the elbow)     |
| **LKD**         | 8             | Left Knee Distal (Left leg, below the knee)       |
| **RKD**         | 10            | Right Knee Distal (Right leg, below the knee)     |

### 1.3.  Processing Workflow

1. **Initialization:** The script mounts Google Drive and points the `OpenDatasetStore` backend to `/content/drive/MyDrive/Datasets/Wearable-Biomechanics`.

2. **Data Ingestion:** Loads the raw dataset for a specified experiment entry (e.g., `experiments_0001`).

3. **Visual Quality Assurance:** Evaluates signal integrity by plotting data distributions (using violin and scatter plots via Plotly) for the active hardware devices.

4. **Extraction:** Passes the dataset through the `extract_and_rename_imus` function utilizing the established sensor mapping dictionary. In here from multiple IMUs in each device (IMU1, IMU2, IMU3) choose the best one, preferebly the the IMU in the device it self (IMU have the largest index IMU3 in 3 Sensor devices or IMU2 in 2 Sensor devices)

5. **Storage:** Commits the finalized, subset DataFrame to the `processed_data` directory within the store, appending the specific tag `selected_for_4ang` to the file.
